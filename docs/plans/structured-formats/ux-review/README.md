# Structured views: rendered review against the mock

The real table, tree, cue and notebook views, drawn by a real relic-server on loopback with real published relics and the viewer's own stylesheet, were screenshotted in an isolated headless Chrome (CDP `Page.captureScreenshot`; 390 by 844 with mobile metrics and touch emulation for phones) and compared with the mock shots in `../mock-shots/`. Every screenshot here is a screenshot; nothing was drawn or generated.

Fixes are in commit `69868f61` and the follow-up that moved the phone hint under the grid. The measured rules are now the `layout` stage of `packages/relic-mcp/test/structured-formats-path.ts`. On the build before the fixes it fails and names all twelve rules (`layout-stage-before.log`); after the fixes it passes (`layout-stage-after.log`).

## Decisions that need a product call

1. The phone inspector offers Copy only; the mock (T9) also has Comment and Suggest edit in the sheet. Today a reader comments through the floating offer beside the cell.
2. The composer names its target by pointer ("Commenting on /cells/1", "/inspection/readings"); the mock names it "Cell 7 · markdown".
3. Escaped bidi controls read three ways: `\u{202E}` in tables, `\u202e` in the tree (the JSON escape), `[U+202E]` in cues and notebooks. The mock draws a "U+202E" chip.
4. Control borders use `--rule-strong`: 1.94:1 light and 1.71:1 dark against the surface, under the 3:1 WCAG 1.4.11 asks of component boundaries. It is a viewer-wide token, so it was not changed here.
5. The column header's Comment control is 17.6 px and appears on hover or selection; a 36 px header cannot hold 44 px. On a phone the header cell's selection offer is the way in.
6. Viewer chrome outside the structured views is under 44 px at 390 (header actions 34 by 53, Reading and Suggesting 25 tall, the suggestions switch 23 tall, the Comments tab 29 wide, composer Post and Cancel). Out of this change's scope.
7. On a phone, notebook Comment controls now appear only on the chosen cell or output (the mock shows none; before, every cell showed one).
8. On a desktop the output Comment control hangs below the output and covers the top edge of the next cell while hovered, as the mock's cell toolbar does.
9. A JSON file the tree refuses still shows the route's View source toggle above its source (J5); a refused table does not (T6).
