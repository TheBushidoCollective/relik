Release 0.14.3

relic-mcp 0.14.3 release notes

Fixes to the plugin, the viewer and cover images. Each item below shipped in this release.

Plugin

  • The plugin manifest is now generated to follow the release version.
  • The plugin is updated to the fixed cover client.

Viewer

  • Image comment markers now match the add control.
  • The OpenTimelineIO player verifies the presented decoder frame before paint when playback is paused, and the behaviour is documented.

Cover images

  • Annotations are kept out of cover frames.
